# Supabase migrations

No migrations have been applied to the Alteo Supabase project yet. The project is intentionally left unchanged while backend contracts and Row Level Security design are reviewed.

Place future migration files here using timestamped names, review SQL and permissions, and apply them only after review. A migration must include or accompany security tests for all exposed tables, views, functions and storage policies.

Do not add service-role keys, secrets or production data to migration files. Do not use the Go Ride project as the Alteo database.
